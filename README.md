# Task 4 - Robot Control Panel

## Description

This project is a web-based robot control panel developed using HTML, CSS, JavaScript, PHP, and MySQL.

The application allows users to control the robot using control buttons or Speech to Text. The selected command is stored in a MySQL database and can be retrieved by the robot.

## Live Demo

🔗 https://jouryrobot.rf.gd

## Features

- Forward
- Backward
- Left
- Right
- Stop
- Speech to Text
- Store commands in MySQL
- Responsive interface

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Web Speech API

## How to Run

1. Create a MySQL database.
2. Import the `setup.sql` file.
3. Update the database credentials in `db.php`.
4. Upload the project files to a PHP server such as InfinityFree.
5. Open `index.html`.
